Merge course codes

Tick the course codes that write the same question paper in this session. They show as one row in QP statistics and in the Hall Allocation sheet. Seating is not changed: candidates are still grouped and seated by course as usual.

Why repeated register numbers are subtracted

A student can write only one paper in a session. These students appear under two (or more) papers of the same session on their hall tickets, so adding the papers up would count them twice. Usually one of the codes is an old-scheme subject whose equivalent is not mapped yet: both codes are the same question paper. So each student is counted once for this session, and the extra count is subtracted from the session and day totals. The paper rows above still show each paper's own count. To merge the papers properly, add the equivalent subject.

Hall marking guide for DOTE attendance

Upload the DOTE attendance sheet PDFs. They can only be printed, so they are not changed: the app reads each row's S.No and register number, finds the hall in this app's seating for the date and session printed on the sheet, and lists, page by page, which S.No range to bracket for each hall on the printed copy.

QR sticker hall separation guide

Upload DOTE's answer-book QR sticker PDF (e.g. 23102026_FN.pdf; the date and session come from the file name, otherwise from the date and session picked above). It is not changed: the app reads each sticker's register number and gives a guide PDF that shows every sticker page with each sticker's hall and red lines where to cut — one guide page for each sticker page.

Export & import

Export saves every nominal roll, hall ticket, mapping, candidate edit, exam date, hall and seat allocation into one JSON file. Import adds that data back (existing files with the same name are replaced). Backups from the older version of the app can be imported too.

Reset all data

Deletes everything this app has saved in this browser: nominal rolls, hall tickets, candidate edits, mappings, exam dates, halls and seat allocations. This cannot be undone. Export a backup first if you may need the data again.

⚠ Please verify equivalent subjects. Old-scheme subjects are merged with their newer subject using the built-in DOTE equivalents table and your own mappings in Equivalent Subjects Mapping; anything not in either is counted under its own subject code.
